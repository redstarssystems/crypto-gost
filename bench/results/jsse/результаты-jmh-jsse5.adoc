== Что измеряет этот прогон

Уровень `crypto-gost-jsse` — JSSE-обёртка поверх `crypto-gost-tls13`. Замеры идут через `SSLEngine` (стандартный программный интерфейс JSSE), проверка сертификата отключена (пустой TrustManager).

Прогон повторяет методику прогона 3 (три запуска JVM) и делается после двух крупных изменений: арифметики кривой (с 0.7.1) и новой реализации Стрибога.

== Сравнение с прогоном 4 и с 0.7.1

*Прогон 4* — 2026-07-15, JDK 25.0.3, один запуск JVM. В таблице рукопожатий прогона 4 единица указана неверно: «95 504 ops/s» и «58 846 ops/s» — это 95,5 и 58,8 рукопожатий в секунду (время операции 10,5 и 17,0 мс в той же таблице).

=== Анализ

. *Рукопожатие быстрее 0.7.1 в 2,2 раза, с клиентским сертификатом — в 2,6 раза.* Основной вклад — арифметика кривой: генерация ключа ECDHE быстрее в 3–4 раза, подпись в 2,3 раза, проверка подписи в 1,5 раза (см. отчёт `bench/results/tls/результаты-jmh-tls-2026-11-16.adoc`).

. *Вклад нового Стрибога — около 13 %.* 15 ноября на коде до замены хеша (три запуска JVM) было 180,5 ± 7,0 и 135,0 ± 3,7; сейчас 203,4 и 153,0. Хеш входит в рукопожатие через хеш стенограммы, HKDF и HMAC сообщений Finished, а также через хеш подписываемых данных; HKDF и вывод ключей теперь быстрее в 2,2 раза.

. *Слой записей без изменений.* Все размеры в пределах ±3 % от 0.7.1. Расхождение с прогоном 4 (до −4 %) — в пределах разницы между сборками JDK и одним запуском JVM против трёх.

. *Соотношение mutualAuth/fullHandshake* — 1,33 (в прогоне 4 было 1,62): дешёвая теперь проверка открытого ключа и подписи сильнее ускорила путь с двумя проверками.

== Открытые вопросы

. Выделения при скалярном умножении (около 1,4 МБ на подпись или ключ ECDHE) — главный оставшийся источник нагрузки на сборщик мусора.
. Стоимость проверки сертификата в `GostX509TrustManager` на уровне JSSE не измерялась.
. Возобновление по PSK на уровне JSSE отдельным бенчмарком не измеряется (на уровне tls13 — `PskResumptionBench`).
. Сравнение с SunJSSE на классических алгоритмах и многопоточная пропускная способность рукопожатий.

== Воспроизведение прогона

[source,bash]
----
mvn -o install -DskipTests
cd bench/jsse && mvn -o package
java -jar target/benchmarks.jar JsseHandshakeBench -wi 5 -i 5 -f 3 -w 10s -r 10s -jvmArgs -Xmx2g
java -jar target/benchmarks.jar JsseRecordBench -wi 5 -i 5 -f 3 -w 10s -r 10s -jvmArgs -Xmx2g
java -jar target/benchmarks.jar '(JsseHandshakeBench.fullHandshake|JsseRecordBench.roundTrip)' -prof gc -wi 2 -i 3 -f 1 -w 5s -r 5s -jvmArgs -Xmx2g
----

Перед запуском проверить, что EPP всех ядер `performance`: `cat /sys/devices/system/cpu/cpu*/cpufreq/energy_performance_preference`.
